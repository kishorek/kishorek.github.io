# Prompt Gallery

Prompts, kept beside the pictures and pages they made.

Open `index.html` in a browser. No server is required.

## Add a piece

Append an object to `PROMPTS` in `gallery.js`.

- `media: "image"` needs `image` and `alt`. Put the file in `assets/`.
- `media: "text"` needs `output`, a string.
- `tags`, `palette`, `format`, and `caption` are optional.

Images on the shelf are shown smaller than the source file. Click a sheet to open it larger.
